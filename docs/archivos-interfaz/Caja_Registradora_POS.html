Cómo activar la cámara

1. Lo más estable: abrirla con HTTPS

Si abres el archivo .html directo desde Archivos, Descargas o WhatsApp, el navegador no muestra el candado ni recuerda el permiso, y por eso se pierde cada vez. Sube el archivo a una dirección https:// (tu sitio, GitHub Pages o Netlify) y ábrelo desde Chrome: ahí sí aparece el candado y el permiso se queda guardado.

2. Revisa el permiso del celular

Ajustes de Android → Apps → Chrome → Permisos → Cámara → Permitir.

3. Revisa el permiso dentro de Chrome

Chrome ⋮ → Configuración → Configuración de sitios → Cámara → deja activado «Preguntar antes de acceder».

Mientras tanto

Usa el botón Foto: abre la cámara del celular, tomas la foto del código y la lectura se hace igual, sin necesitar este permiso.
